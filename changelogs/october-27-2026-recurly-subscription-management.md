October 27th introduces Revolv3 as a new payment gateway, bringing intelligent transaction routing and improved authorization rates to Recurly merchants — enablement is required, so reach out to get started. Merchants using Custom Gateway Routing can now also opt in to Gateway Failover, with the ability to designate a backup gateway per transaction via API, a long-awaited capability for merchants prioritizing transaction resilience and orchestrated routing. On the API side, Adyen token support via the `payment_gateway_references` array is now available, and Checkout.com and Nuvei merchants will see improved Mastercard TLID handling automatically.

Rounding out the release, Stripe Level 2/3 tax data handling has been corrected to ensure proper interchange qualification, a CyberSource Level 2 fix for American Express is live for migrated merchants, and an App Store Apple Pay past due state issue has been resolved — all behind-the-scenes with no action required.

| Oct 27       | Revolv3 Gateway        | New         | Low              | Recurly now supports Revolv3, a payment orchestration gateway designed to improve authorization rates by intelligently routing transactions across multiple payment processors. **Action required:** enablement is required before processing — see our Revolv3 documentation after release for supported configuration and setup details.                                                                                              |
| Oct 27       | V3 API                 | Enhancement | Medium           | Merchants can now pass Adyen tokens directly via the V3 API using two new `reference_type` enums: `adyen_shopper_reference` and `adyen_payment_method` when using the `payment_gateway_references` array. Existing API fields remain supported and no integration changes are required. See updated documentation and integration guides after release for implementation details.                                                      |
| Oct 27       | Custom Gateway Routing | Enhancement | High             | Recurly now supports Gateway Failover for merchants using Custom Gateway Routing, with the added ability to specify a dedicated backup gateway per transaction via API — giving you greater control over transaction resilience and redundancy. Integration and configuration changes are required to take advantage of this feature — contact your Recurly representative or Support team to get started.                              |
| Oct 27       | Checkout.com Gateway   | Enhancement | Low              | We have updated handling of the Mastercard TLID field on the gateway, allowing sending the ingested data moving forward. | Oct 27       | Nuvei Gateway          | Enhancement | Low              | We have updated handling of the Mastercard TLID field on the gateway, allowing sending the ingested data moving forward. | Oct 27       | Stripe Gateway         | Bug fix     | Medium           | Recurly has updated how tax data is sent to Stripe for Level 2 and 3 processing, ensuring taxes are correctly mapped at the invoice **or** line item level to qualify for interchange savings. No changes are required if you are not using Level 2/3 processing on Stripe. |
| Oct 27       | App Management         | Bug fix     | Low              | We have resolved an issue where external Apple Pay subscriptions' past due state was not correctly handled when the grace period ended without a successful payment. No configuration changes are required.                                                                                                                         |
