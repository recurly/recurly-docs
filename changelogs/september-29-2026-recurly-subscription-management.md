| Sep 29       | Ebanx Gateway    | Enhancement | Medium           | Recurly will support credit card processing in Latin American countries through the EBANX gateway. Merchants wishing to enable this feature must complete configuration steps at both Recurly and EBANX, and integration changes are necessary. See our updated [EBANX documentation](https://docs.recurly.com/recurly-subscriptions/docs/ebanx-gateway) and integration guide for supported countries and setup details after release.                                                                                                                                  |
| Sep 29       | dLocal Gateway   | New         | Low              | Recurly now supports dLocal as a gateway, enabling GCash as a payment method for merchants processing in the Philippines. Merchants must complete enablement with both dLocal and Recurly before processing. See dLocal documentation for supported configuration and setup details after release.                                                                                                                                                                                                                                                                       |
| Sep 29       | GCash Wallet     | New         | Low              | Recurly now supports GCash through the dLocal gateway for merchants processing in the Philippines, available exclusively via Recurly.js for both subscriptions and one-time purchases. See our dLocal and GCash integration guides for setup details after release.                                                                                                                                                                                                                                                                                                      |
| Sep 29       | Payment Settings | Enhancement | Medium           | New mandate management settings will be available in Payment Settings configuration for merchants using certain LATAM and APAC alternative payment methods. For Ebanx APMs, setting a custom mandate buffer percentage will be supported, and a new configuration for handling mandate revocation will also be available. No changes are required to settings if you do not wish to change how your integration works today. See [documentation](https://docs.recurly.com/recurly-subscriptions/docs/payment-settings#enabling-mandate-settings) for additional details. |
