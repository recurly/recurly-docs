# Definition

<div class="rp-definition">The sign-up declines trendalyzer dashboard is a pivotable breakout dashboard for sign-up decline data. Select a primary dimension and up to two breakout dimensions, choose a metric — decline rate, total transactions, or failed transactions — and the dashboard rebuilds the chart and table to match.</div>

# Key details

This breakout dashboard lets you pivot fields to view different orders and switch between metrics like decline rate, failed transactions, and total transactions. The top chart displays your primary dimension over time, while the table breaks that dimension down by your selected breakout dimensions.

## General filters (Top left corner)


<Image src="https://files.readme.io/d14cb6d2bc303105f82938656fed93db7f501394c79007ee08adac30558ef225-Signup_Declines_Trendalyzer.png" align="center" width="75%" border={true} />


<ul class="rp-list">
  <li><strong>Timeframe</strong>: Analyze data for different monthly timeframes.</li>
  <li><strong>Invoice creation date</strong>: Choose a specific date range, up to the last 18 months, using the start and end date dropdowns.</li>
  <li><strong>Primary dimension</strong>: Focus on a primary metric by selecting from payment type, brand, gateway, or failure type.</li>
  <li><strong>Dimension breakout 1</strong>: Select an additional dimension from the list, or view all dimensions.</li>
  <li><strong>Dimension breakout 2</strong>: Choose another dimension from the list, or view all dimensions.</li>
  <li><strong>Metric</strong>: Pick the key metric for analysis — decline rate (%), total transactions, or failed transactions.</li>
  <li><strong>Gateway type</strong>: Specify which gateway to view in the data.</li>
  <li><strong>Failure type</strong>: Filter by failure reason, choosing the top 5, top 10, or all reasons.</li>
</ul>
