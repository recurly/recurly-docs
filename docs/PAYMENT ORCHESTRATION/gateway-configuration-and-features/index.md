# Definition

<div class="rp-definition">Gateway configuration and features covers the configurations and tools available in Recurly for managing payment processing — including multiple gateway support, custom routing, gateway failover, fraud management, credit card vaulting, and multi-currency transactions. Together these features provide a foundation for managing transactions, reducing risk, and supporting global commerce.</div>
