# Definition

<div class="rp-definition">Invoice configuration is the suite of tools that lets you control how invoices are generated, presented, and managed throughout the billing lifecycle. From automation to personalization, these features help businesses run efficient billing cycles, maintain a professional image, and handle credits and chargebacks with confidence.</div>
