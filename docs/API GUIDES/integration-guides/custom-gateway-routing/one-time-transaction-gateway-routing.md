# Overview

This guide shows you how to use the V3 [Purchases endpoint](https://recurly.com/developers/api/v2021-02-25/index.html#operation/create_purchases) to create new purchases using a gateway_code for a non-recurring transactions.&#x20;

This will allow you to target specific gateways using the `v3/purchases` endpoint by placing  `gateway_code` in the purchases call body once.

### Prerequisites & limitations

* Familiarity with Recurly’s API and basic REST concepts
* [Completed the Quickstart Guide](https://docs.recurly.com/recurly-subscriptions/docs/quick-start-guide#/)
* You have line items, or catalogue items.
* A gateway and payment method that supports one time transactions.

***

# Definition

**Creating Purchases** refers to the process of generating new customer accounts alongside a one time transaction in a single, consolidated call to the Recurly Purchases endpoint. This streamlines checkout experiences by bundling all required resources into one request.

***

# Creating Subscriptions

## Step 1: Generate a Purchase Request

**Use** a supported library, Recurly.js or our APIs with raw card or billing payment information.

**Send** a request to the create`purchases` endpoint on Recurly’s API, including:

* **Customer account data** (e.g., code, name, billing info, phone number, email address, tax ID/tax type)
* **Line items** (custom or item codes)
* **Gateway Code** in one place:
  * Once at the billing info level (controls the transaction behavior).

There are other fields available in our documentation. Below is a hyper-specific example to show the `gateway_code` placement specifically.

```json One Time Transaction with Routing
{
    "currency": "USD",
    "line_items": [{
        "unit_amount": "10.00",
        "quantity": 1,
        "description":"Description",
        "type": "charge",
        "product_code":"1001"
        }
    ],
    "account": {
        "code": "new_account_1",
        "billing_info": {
            "token_id": "rjs-token", // Only send if using Recurly.js
            "gateway_code": "your-gateway-code" // Controls the current purchase
        }
    }
}
```

***

## Step 2: Process the purchase response

A successful purchase returns an **InvoiceCollection**, which contains any charge or credit invoices generated by the request.

***

## Step 3: Verify and finish

After a successful purchase, you can confirm the details via the Recurly Admin UI or by calling Recurly’s API to list your new account, purchase, or invoice.
