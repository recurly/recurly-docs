## Overview

Different countries require different invoicing information. Mandate configuration allows to set up the rules for processing invoicing information.  It defines when a mandate applies and how documents are handled - so the system can evaluate rules (country, customer, document type, etc.) and apply the correct mandate and logic automatically.
