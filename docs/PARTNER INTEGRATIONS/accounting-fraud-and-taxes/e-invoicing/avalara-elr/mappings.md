## Overview

Display available mappings by mandate so you can view, clone or edit mapping templates.
Default mappings are provided as a starting point for you.  You can clone a default mapping and customize for your needs.

## Default Mappings

Default mappings are provided as a starting point for you.  You can clone a default mapping and customize for your needs.

## Creating a New Mapping

Select a country mandate to see which input fields apply. The system retrieves the available input fields for you to configure.  The list depends on the mandate.
